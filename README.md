# 📘 Excel_derivatives

**Excel_derivatives** is a collection of structured Excel models, datasheets, and assumption frameworks designed to explore and apply concepts in equity and financial derivatives. The repository demonstrates practical applications of option pricing, futures contracts, payoff diagrams, and scenario-based analysis, all built with clear assumptions and formulas.

---

## 📂 Repository Structure
- **/Datasheets** → Market assumptions and input data  
- **/Models** → Excel models for derivatives and financial instruments  
- **/Payoff_Diagrams** → Visual payoff structures for options and futures  
- **/Three_Statement_Model** → Integrated Income Statement, Balance Sheet, and Cash Flow model based on assumptions  

---

## ✨ Key Features
- Assumptions-driven models for clarity and flexibility  
- Linked formulas demonstrating real-world derivative mechanics  
- Sensitivity analysis and scenario testing  
- Clean, organized Excel structures suitable for both learning and professional use
